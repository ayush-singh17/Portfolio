# Ayush Singh — Personal Portfolio Website

A clean, modern, and responsive personal portfolio webpage built using pure **HTML5** and **CSS3**, designed to showcase projects, education, technical skills, and interests. Hosted and published via **GitHub Pages**.

🔗 **Live Demo:** [https://ayush-singh17.github.io/portfolio/](https://ayush-singh17.github.io/portfolio/) *(Update with your repository name if different)*

---

## 📌 Features

- **Hero Section:** Profile photograph, brief introduction, and call-to-action buttons.
- **About Me:** Overview of background, academic focus at MIT Manipal, and career goals.
- **Education & Certifications:** Structured timeline covering B.Tech (IT), Amazon ML Summer School 2026, and professional certifications.
- **Featured Projects:** Highlights of core engineering projects with architecture details and tech stack tags:
  - *JournalFinder* (Information Retrieval & Journal Recommendation Engine)
  - *PMinds* (AI Knowledge Graph & Microservices Architecture)
  - *Movie Ticket Booking System* (Distributed Booking with Concurrency Control)
- **Technical Skills:** Categorized layout (Languages, Frontend, Backend, Databases, ML/IR, Tools & DevOps).
- **Interests & Hobbies:** Personal highlights outside of tech (Art watching, Reading, Gaming).
- **Contact & Socials:** Direct links to reach out via Email, GitHub, and LinkedIn.
- **Fully Responsive:** Custom mobile navigation and media queries for desktop, tablet, and mobile screens.

---

## 🛠️ Built With

- **HTML5:** Semantic markup structure (`<header>`, `<nav>`, `<section>`, `<footer>`).
- **CSS3:** Custom styles, CSS variables, flexbox, CSS grid, smooth scroll, and keyframe transitions.
- **Google Fonts:** *Inter* & *Playfair Display*.
- **Font Awesome:** Minimal vector icons.

## 🌐 Deploying to GitHub Pages

To publish this website online for free via GitHub Pages:

1. **Initialize Git & Push to GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit: portfolio website"
   git branch -M main
   git remote add origin https://github.com/ayush-singh17/portfolio.git
   git push -u origin main
   ```

2. **Enable GitHub Pages:**
   - Go to your repository on GitHub.
   - Navigate to **Settings** > **Pages** (under the "Code and automation" menu).
   - Under **Build and deployment > Source**, select **Deploy from a branch**.
   - Select branch **`main`** and folder **`/(root)`**, then click **Save**.

3. **View the live site:**
   Within 1–2 minutes, your website will be live at:
   ```
   https://ayush-singh17.github.io/portfolio/
   ```
